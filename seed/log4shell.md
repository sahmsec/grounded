## Scope

Named, publicly disclosed software vulnerabilities and the identifiers used to
track them. This includes CVE numbers, what a CVE identifier is and who issues
one, severity scoring, and how a disclosed flaw moves from report to patch to
exploitation in the wild.

Log4Shell is the worked example: a remote code execution flaw in the Apache
Log4j Java logging library, disclosed in December 2021, exploited by getting
attacker-controlled text into a logged message. It is covered here as a case
study in how a single library flaw reaches an enormous number of systems
through the software supply chain.
